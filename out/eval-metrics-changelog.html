3. 新增指标详解

3.1 Boundary IoU（边界交并比）

来源： Cheng et al., "Boundary IoU: Improving Object-Centric Image Segmentation Evaluation", CVPR 2021

动机： 标准 IoU 对大面积掩码的边缘误差不敏感。Boundary IoU 仅在边界带内计算 IoU，直接反映边缘精度。

计算步骤：

1. 形态学腐蚀：eroded = 1 − MaxPool2d(1 − mask, kernel=5, stride=1, padding=2)
2. 提取内边界：boundary = mask − eroded
3. 边界 IoU = |boundary_pred ∩ boundary_gt| / |boundary_pred ∪ boundary_gt|

3.2 Precision（精确率）

定义： 预测为前景的像素中，实际为前景的比例。

Precision = TP / (TP + FP) = intersection / pred_sum

意义： 高 Precision 表示模型预测的前景区域很少有误报（假阳性）。

3.3 Recall（召回率）

定义： 实际为前景的像素中，被正确预测的比例。

Recall = TP / (TP + FN) = intersection / gt_sum

意义： 高 Recall 表示模型很少遗漏前景区域（假阴性）。

3.4 指标体系对比

指标评估维度对什么敏感来源
Dice整体重叠度面积匹配已有
IoU整体重叠度面积匹配（比 Dice 更严格）已有

4.2 核心代码

边界提取辅助函数（evaluate.py:23-28）：

# ---- 评估专用指标函数 ----
BOUNDARY_WIDTH = 2

def _boundary(m, w=BOUNDARY_WIDTH):
    """提取二值 mask 的内边界带（mask - erode(mask)）"""
    k = 2 * w + 1
    eroded = 1 - F.max_pool2d(1 - m[None, None], k, 1, w)[0, 0]
    return m - eroded

逐样本指标计算（evaluate.py:135-145）：

# Boundary IoU
pred_bd = _boundary(pred_i)
gt_bd = _boundary(gt_i)
bd_inter = (pred_bd * gt_bd).sum()
bd_union = ((pred_bd + gt_bd) > 0).float().sum()
all_boundary_iou.append((bd_inter / (bd_union + 1e-7)).item())

# Precision / Recall（复用已有 intersection）
all_precision.append((intersection / (pred_i.sum() + 1e-7)).item())
all_recall.append((intersection / (gt_i.sum() + 1e-7)).item())

冗余消除（删除重复的 overlap 变量）：

-            overlap = (pred_i * gt_i).sum()
             union_mask = ((pred_i + gt_i) > 0).float().sum()
-            iou = (overlap / (union_mask + 1e-7)).item()
+            iou = (intersection / (union_mask + 1e-7)).item()

4.3 实现要点

  • F.max_pool2d 的 4D 输入要求： pred_i 是 2D (H, W)，通过 m[None, None] 升维到 (1, 1, H, W)，计算后 [0, 0] 降维回来。
  • 腐蚀实现： 对 1 - mask 做 max_pool2d 等价于对 mask 做 min_pool2d（形态学腐蚀）。
  • intersection 复用： Precision 和 Recall 的分子 TP 就是 intersection = (pred_i * gt_i).sum()，已在 L126 计算过。
  • 空 mask 安全： 全零 mask 的 boundary 也全零，eps=1e-7 防止除零，返回 ≈0。与现有 Dice/IoU 的处理方式一致。
