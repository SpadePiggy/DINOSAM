概述

本文方法的核心在于：将 SAM 原有的 ViT-B 图像编码器替换为冻结的 DINOv3 ViT-B/16 预训练骨干，通过轻量可训练适配器将 DINOv3 的通用视觉表征对齐到 SAM 的 256 维特征空间，从而使掩码分支和深度分支可以共享同一套编码器输出，无须修改下游解码器结构。

为系统性评估适配器设计对迁移效果的影响，我们设计了三种结构差异显著的适配器——MoNA（多尺度卷积）、FCAdapter（纯全连接瓶颈）和 DualAttnAdapter（双重注意力）——作为消融实验的核心变量。三者保持相同的瓶颈压缩比和残差结构，仅在核心变换机制上存在差异。

3.1 整体架构

DINOSAM 由共享的图像编码器和两个独立解码分支组成。当编码器类型指定为 dinov3 时，构造函数实例化 DINOv3MonaEncoder 替代 SAM 原生 ViT-B 编码器。此替换对下游分支完全透明——两个解码分支的结构、参数和前向逻辑与使用 SAM 编码器时完全一致。

这一设计确保了消融实验的公平性：编码器变更所带来的性能差异可完全归因于骨干表征能力和适配器设计，而非下游结构差异。

3.2 DINOv3 编码器与特征对齐

设计动机

SAM 的原生 ViT-B 在大规模分割数据上预训练，具备强分割先验，但其表征受限于分割任务本身的监督信号。DINOv3 ViT-B/16 经自监督预训练获得的视觉表征已被证明在多种下游任务中展现出优越的迁移性能。然而，DINOv3 的输出维度 (768) 与 SAM 的内部特征维度 (256) 不一致，且两者的图像预处理流程存在显著差异，需要通过适配模块实现特征空间对齐。

3.3 适配器设计（核心消融模块）

消融逻辑

为系统性评估不同归纳偏置对稠密预测迁移效果的影响，设计三种适配器。每种保持相同的瓶颈压缩比（768/8=96）和残差连接结构，仅在核心变换机制上存在差异：

  • MoNA：引入多尺度空间卷积 → 评估局部空间信息的贡献
  • FCAdapter：仅保留通道变换 → 作为通道基线
  • DualAttnAdapter：引入全局注意力 → 评估全局上下文建模的价值

三者对比系统性地回答：对于从通用骨干到稠密预测任务的特征适配，何种归纳偏置最为有效？

3.3.3 FCAdapter — 全连接瓶颈适配器（通道基线）

3.3.4 DualAttnAdapter — 双重注意力适配器

引入全局注意力机制作为第三种归纳偏置。设计基于 DANet 的双重注意力思想：同时建模空间位置间和通道间的长程依赖。注意：DualAttnAdapter 没有瓶颈压缩结构，参数量和计算复杂度与 MoNA/FC 存在差异——这是有意为之，消融目标是评估归纳偏置类型的影响。

3.5 损失函数

掩码分支和深度分支分别使用独立的损失函数，与 SAM 编码器方案完全一致，不因编码器替换而改变：

Phase 1 掩码损失

Lmask = Ldice(Mpred, Mgt) + MSE(q̂, q)

其中 Dice loss 在 sigmoid 激活后计算：Ldice = 1 − 2|pred∩gt| / (|pred|+|gt|+ε)。IoU loss 为预测 IoU 与真实 IoU 的均方误差。

Phase 2 深度损失

Ldepth = λ × MSE(dpred, dgt)

深度标签归一化为除以 100，λ 为深度损失权重（默认 1.0）。
