一、项目总览与架构概述

DINOSAM（Depth-aware SAM）在 SAM (ViT-B) 的基础上扩展了深度预测能力。核心思路是：在 SAM 的分割掩码分支之外，增加一个外部深度分支（outer prompt encoder + depth decoder），利用分割掩码作为中间表征来预测目标的深度值。

项目支持两种图像编码器主干：

  • SAM 主干（--encoder sam）：使用 SAM 原生的 ViT-B/16 图像编码器，冻结编码器参数
  • DINOv3 主干（--encoder dinov3）：将 SAM 的图像编码器替换为 DINOv3 ViT-B/16 + 可训练适配器

二、SAM 主干方向

2.1 模型结构

图像编码器：SAM ViT-B/16（冻结）

当 encoder_type="sam" 时，使用 SAM 原生的 ViT-B/16 图像编码器。编码器参数在训练过程中始终冻结。

输入预处理流程（DepthSam.preprocess()）：

  1. 将图像最长边缩放到 1024px（保持宽高比）
  2. 使用 SAM 的 pixel_mean/pixel_std 进行归一化
  3. 填充到 1024×1024

输出：(B, 256, 64, 64) 的图像特征

# depth_sam.py:134-146 — 预处理流程
def preprocess(self, x: torch.Tensor) -> Tuple[torch.Tensor, Tuple[int, int]]:
    oldh, oldw = x.shape[2], x.shape[3]
    newh, neww = ResizeLongestSide.get_preprocess_shape(oldh, oldw, self.img_size)
    x = F.interpolate(x, size=(newh, neww), mode="bilinear", align_corners=False,
                      antialias=True)
    input_size = (newh, neww)
    x = (x - self.sam.pixel_mean.unsqueeze(0)) / self.sam.pixel_std.unsqueeze(0)
    padh = self.img_size - newh
    padw = self.img_size - neww
    x = F.pad(x, (0, padw, 0, padh))
    return x, input_size

掩码分支（Mask Branch）— SAM 内部

掩码分支直接使用 SAM 的原始 prompt_encoder + mask_decoder：

  • Inner PromptEncoder：将点提示（point_coords, point_labels）编码为稀疏嵌入和密集嵌入
  • MaskDecoder：基于 TwoWayTransformer，输出 4 个掩码候选 + IoU 预测（此处使用 multimask_output=False，只取 1 个掩码）

输出：low_res_masks (B,1,256,256)、iou_pred (B,1)、masks (B,1,H,W)

深度分支（Depth Branch）— 外部扩展

深度分支是 DINOSAM 的核心创新，结构上模仿 SAM 的掩码分支，但用于深度回归：

  • Outer PromptEncoder：与 SAM 内部 PromptEncoder 结构完全相同，但接收低分辨率掩码（来自掩码分支的输出，经过 detach）作为 mask input
  • DepthMaskDecoder：修改自 SAM MaskDecoder，区别如下表：

2.2 消融模块详解

消融模块 1：迭代式提示生成（Iterative Prompt Generator）

基于 micro-SAM 的思路简化实现，用于迭代训练和推理。每次迭代：

  1. 将预测掩码与 GT 掩码对比，计算误差区域
  2. 从遗漏前景（missed foreground = GT 有但预测没有）采样 1 个正点
  3. 从假阳性区域（false positive = 预测有但 GT 没有）采样 1 个负点
  4. 将新点追加到已有提示中
  5. 以概率 mask_prob 将上一轮低分辨率掩码作为 mask input

class DepthIterativePromptGenerator:
    def __call__(self, gt_masks, pred_masks):
        expected_diff = pred_masks - gt_masks
        pos_region = (expected_diff == -1)   # 遗漏前景区域
        neg_region = (expected_diff == 1)    # 假阳性区域
        # 对每个样本采样 1 正 + 1 负点
        # 回退策略：若无误差区域，则从重叠区域/GT前景/背景边界采样

消融模块 2：深度解码器掩码（Decoder Mask Output）

DepthMaskDecoder 除了输出深度标量，还输出一个辅助掩码。这个掩码在 Phase 2 的迭代训练中用于：

  • 计算辅助 dice_loss（监控深度分支的掩码质量）
  • 在迭代深度训练中，基于 decoder mask 与 GT 的误差生成新的点提示

消融模块 3：Mask Input 机制

在迭代训练中，可选地将上一轮的低分辨率掩码传递给下一轮作为 mask_input。这通过 PromptEncoder 的 mask 编码通道（mask_in_chans=16）实现。控制参数为 --mask_prob，以概率随机决定是否传递。

三、DINO 主干方向

3.1 模型结构

图像编码器：DINOv3 ViT-B/16 + 适配器

当 encoder_type="dinov3" 时，使用 DINOv3MonaEncoder 替代 SAM 的图像编码器：

  • DINOv3 骨干：ViT-B/16，12层 Transformer，embed_dim=768，使用 RoPE 位置编码
  • 骨干参数完全冻结，只有适配器和投影层可训练
  • 适配器：两个串联的适配器（adapter1 + adapter2），类型可选
  • 投影层：Linear(768 → 256)，将 DINOv3 输出维度对齐到 SAM 的 256 维

输出与 SAM 编码器完全对齐：(B, 256, 64, 64)

# dinov3_encoder.py:16-110 — DINOv3MonaEncoder
class DINOv3MonaEncoder(nn.Module):
    def __init__(self, checkpoint_path, img_size=1024, embed_dim=768, out_dim=256,
                 adapter_type="mona"):
        # 加载预训练 DINOv3 ViT-B/16 并冻结
        self.backbone = DinoVisionTransformer(
            img_size=img_size, patch_size=16, embed_dim=768, depth=12,
            num_heads=12, ffn_ratio=4,
            pos_embed_rope_base=100,        # RoPE 位置编码
            n_storage_tokens=4,              # 存储 token
            # ...
        )
        # 两个串联适配器
        self.adapter1 = get_adapter(adapter_type, embed_dim, factor=8)
        self.adapter2 = get_adapter(adapter_type, embed_dim, factor=8)
        # 维度投影
        self.projection = nn.Linear(embed_dim, out_dim)  # 768 → 256

    def forward(self, images):
        x = F.interpolate(images, size=(self.img_size, self.img_size), ...)
        x = (x - self.pixel_mean) / self.pixel_std
        features = self.backbone.forward_features(x)
        patch_tokens = features["x_norm_patchtokens"]  # (B, N, 768)
        x = self.adapter1(patch_tokens, (H, W))
        x = self.adapter2(x, (H, W))
        x = self.projection(x)  # (B, H*W, 256)
        x = x.view(B, H, W, -1).permute(0, 3, 1, 2)  # (B, 256, H, W)
        return x, input_size

掩码分支 & 深度分支

在 DINOv3 主干方向，掩码分支和深度分支与 SAM 主干方向完全相同。区别仅在于图像编码器部分。DINOv3 编码器的输出通过适配器和投影层映射到 (B, 256, 64, 64)，后续所有处理逻辑不变。

3.2 消融模块详解

DINOv3 方向有 3 种可选适配器，是核心的消融维度：

适配器 A：MoNA（默认）

多尺度深度卷积适配器 + 瓶颈 MLP

结构：LayerNorm*γ + x*γx → Linear(768→96) → MonaOp → GELU → Dropout(0.1) → Linear(96→768) → 残差

MonaOp：3 路深度卷积（3×3, 5×5, 7×7）取均值 + 恒等 → 1×1 投影

特点：引入多尺度空间信息，参数量适中

适配器 B：FC（纯全连接）

纯 MLP 瓶颈适配器，无空间卷积

结构：LayerNorm*γ + x*γx → Linear(768→96) → GELU → Dropout(0.1) → Linear(96→768) → 残差

特点：无空间操作，仅通道维度变换。hw_shapes 参数被接受但不使用（接口兼容）

适配器 C：Dual Attention（双重注意力）

基于 DANet 的位置注意力 + 通道注意力并行适配器

结构：将序列特征 reshape 为 2D → PAM + CAM 并行 → 取均值 → 全局残差

组件结构作用
PAM（Position Attention）Q/K: Conv1x1(768→96), V: Conv1x1(768→768) → softmax 注意力建模空间位置间的长程依赖
CAM（Channel Attention）直接计算通道间注意力矩阵 → max-subtract 稳定化 → softmax建模通道间语义关联

注意：PAM 和 CAM 内部不包含残差连接（由 DualAttnAdapter.forward() 统一添加），这与原始 DANet 有所不同。

# adapters/dual_attn_adapter.py:55-79 — DualAttnAdapter
class DualAttnAdapter(nn.Module):
    def __init__(self, in_dim, factor=8):
        self.pam = PAM_Module(in_dim, factor)
        self.cam = CAM_Module(in_dim)

    def forward(self, x, hw_shapes=None):
        B, N, C = x.shape
        H, W = hw_shapes
        identity = x
        x_2d = x.reshape(B, H, W, C).permute(0, 3, 1, 2)
        attn_out = (self.pam(x_2d) + self.cam(x_2d)) / 2.0
        out = attn_out.permute(0, 2, 3, 1).reshape(B, N, C)
        return identity + out

        param.requires_grad = False            # SAM ViT-B 总是冻结

五、数据集与提示生成

DepthDataset 数据格式

目录结构：根目录下按深度值分子文件夹，每个文件夹包含同名的 .jpg 图像和 .png 掩码。

深度值编码：文件夹名 "0" → depth=0，"10" → depth=10，"f10" → depth=-10（前缀 f 表示负数）

深度归一化：depth / 100.0（训练时使用归一化值，评估时还原到原始尺度）

点提示提取

  1. 对 GT 掩码进行连通域分析（scipy.ndimage.label）
  2. 按面积降序排列连通域
  3. 取最大的 max_points 个连通域的质心作为正点提示
  4. 回退策略：无前景区域时使用图像中心

六、技术总结

核心创新点

  1. 双分支架构：在 SAM 的分割掩码分支之外，增加外部深度分支（Outer PromptEncoder + DepthMaskDecoder），利用分割掩码作为深度预测的条件输入
  2. 权重初始化策略：深度分支从 SAM 内部分支复制权重初始化，加速收敛
  3. 两阶段交替训练：Phase 1 训练掩码分支，Phase 2 冻结掩码训练深度分支，避免两个任务相互干扰
  4. 迭代式误差采点：多轮 forward → 比较误差 → 采样新点提示 → 追加到下一轮，逐步细化分割/深度预测
  5. 可插拔编码器：通过统一的 (B, 256, 64, 64) 接口，支持 SAM ViT-B 和 DINOv3 + 适配器两种编码器
