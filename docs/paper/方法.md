# 方法

本章介绍 DINOSAM 的整体方法。我们首先给出问题定义与总体框架（3.1 节），随后依次阐述数据组织与提示合成（3.2 节）、基于冻结 DINOv3 的图像编码器（3.3 节）、mask 分支（3.4 节）与 depth 分支（3.5 节）的结构设计；在此基础上，3.6 节详细描述模拟交互的迭代式训练过程，3.7 节给出全部损失函数的形式化定义，3.8 节说明两阶段训练协议。3.9 节介绍双 DPT 层解耦扩展设计，3.10 节给出推理与评估协议，3.11 节汇总实现细节。

## 3.1 问题定义与总体框架

给定一幅 RGB 图像 $I \in \mathbb{R}^{H \times W \times 3}$ 与一组用户点击形式的稀疏点提示 $P = \{(x_i, y_i, l_i)\}$（$l_i \in \{0, 1\}$ 分别表示背景点与前景点），我们要求模型同时完成两个耦合的任务：

1. **交互式目标分割**：输出目标的二值掩码 $\hat{M} \in \{0,1\}^{H \times W}$，并支持用户通过追加点击迭代修正分割结果；
2. **目标级带符号标量深度回归**：对被分割目标输出一个带符号的标量深度值 $\hat{d} \in \mathbb{R}$。与逐像素深度估计不同，这里的深度是"目标整体"的单一属性——它由数据目录名编码（详见 3.2 节），可正可负，符号具有物理含义。

为什么把两个任务放进同一个模型？直观上，深度回归所需的证据（目标在何处、边界在哪里、占据多大区域）恰好是分割分支已经计算出的中间产物。因此我们采用"**分割先行、深度在后**"的级联结构：depth 分支以 mask 分支输出的掩码为条件（mask 条件化），在共享的图像特征上做第二次解码。整体框架如下：

```
图像 I ──► 图像编码器（冻结 DINOv3 + DPT 融合 + Mona adapter + 线性投影）
              │
              ▼  image embedding (B, 256, 64, 64)   —— 每个训练步只编码一次
   ┌──────────┴───────────────┐
   │ mask 分支                 │ depth 分支
   │ SAM prompt encoder        │ outer prompt encoder（掩码 + 点提示）
   │  + SAM mask decoder       │  + depth-mask decoder
   │ ──► 低分辨率掩码/IoU 预测 │ ──► 标量深度 + 辅助掩码
   └──────────┬───────────────┘
              │ low-res mask（detach）作为 depth 分支的稠密条件
              ▼
        迭代式提示更新（训练时模拟用户点击）
```

该框架建立在 SAM（ViT-B 版本）之上，但将其图像编码器整体替换为冻结的 DINOv3 主干加轻量适配结构，并在 SAM 原有的 prompt encoder / mask decoder 之外新增一条结构对称的深度解码通路。下文逐一展开。

## 3.2 数据组织与提示合成

### 3.2.1 深度标签的目录编码

数据集按"深度类别"组织为目录：每个子目录名即为该目录下全部样本共享的深度真值，例如目录 `10` 表示深度 $+10$，目录 `f10`（"f" 前缀表示负号）表示深度 $-10$，目录 `0` 表示深度 $0$。解析规则为：

$$
d = \begin{cases} -\,\mathrm{float}(s_{1:}) / 100, & s \text{ 以 f 开头} \\ \phantom{-}\,\mathrm{float}(s) / 100, & \text{否则} \end{cases}
$$

其中 $s$ 为目录名。除以 $100$ 是为了把原始深度值（量级约 $[-100, 100]$）归一化到约 $[-1, 1]$，使深度回归目标的数值范围与网络输出的自然量级匹配，避免 MSE 损失在训练初期被大数值主导。评估时再乘回 $100$，全部深度指标均在原始尺度上报告。

每个目录内为成对的 `.jpg` 图像与同名 `.png` 掩码；扫描时只收录图像与掩码同时存在的样本对。掩码以灰度读入后按 `>0` 二值化作为分割真值。主实验使用 `0_sam_train`（1345 个样本）训练、`0_sam_test`（343 个样本）测试。

### 3.2.2 连通域质心自动提示

交互式分割的训练需要初始点提示，但数据集中并无真实用户点击。我们从掩码真值自动合成初始提示：对二值掩码做连通域分析（`scipy.ndimage.label`），按面积从大到小排序，取前 $K$ 个连通域（$K = \min(\texttt{max\_points}, \text{连通域数})$，主配置 `max_points=3`），以每个连通域的像素质心

$$
(c_x, c_y) = \Big( \tfrac{1}{|\Omega_k|} \textstyle\sum_{(x,y) \in \Omega_k} x, \ \tfrac{1}{|\Omega_k|} \textstyle\sum_{(x,y) \in \Omega_k} y \Big)
$$

作为一个正点提示（标签为 1）。选择质心而非随机前景点，是为了让初始提示落在目标内部相对稳定的位置；按面积优先，则保证提示优先覆盖目标的主体部分。若掩码为空（无任何前景连通域），退化为以图像中心 $(W/2, H/2)$ 作为单个正点——这一 fallback 保证了数据流水线对退化样本的封闭性。

### 3.2.3 批组装与 $-1$ padding

不同样本的连通域数不同，合成的提示点数是变长的。自定义的 `collate_fn` 将一个 batch 内的点提示补齐到该 batch 的最大点数：坐标以零填充，标签以 $-1$ 填充。这里利用了 SAM prompt encoder 的既有约定——标签为 $-1$ 的点会被编码为专用的 `not_a_point` embedding，等价于"该位置没有点"，因此 padding 不会向模型注入虚假的提示信息。图像、深度标签、掩码真值与原始尺寸 `original_size` 常规堆叠。

## 3.3 图像编码器：冻结 DINOv3 + 多层 DPT 融合 + 适配器

SAM 原生的图像编码器是在 SA-1B 上以分割为目标预训练的 ViT。我们将其整体替换为自监督预训练的 DINOv3 主干：DINOv3 特征同时携带语义与几何信息，更适合"分割 + 深度"的双任务；同时冻结主干、只训练轻量适配结构，可以在小数据集（千量级样本）上避免灾难性遗忘并大幅降低训练开销。

### 3.3.1 冻结的 DINOv3 ViT-B/16 主干

主干为 DINOv3 ViT-B/16：12 层 Transformer、embed_dim = 768、12 头、patch 大小 16、FFN 比例 4，采用 RoPE 旋转位置编码（`rope_base=100`、坐标 separate 归一化、rescale 系数 2、fp32 计算）、4 个 storage token、LayerScale 初值 $10^{-5}$。从官方 checkpoint 严格（`strict=True`）加载后，**全部主干参数冻结**（`requires_grad=False`），且在每个训练阶段开始时再次显式冻结以防状态漂移。

输入预处理：图像以双线性插值缩放到 $1024 \times 1024$，随后做 ImageNet 均值方差归一化（均值/方差按 $[0,255]$ 值域缩放）。$1024/16 = 64$，故 patch token 构成 $64 \times 64$ 的空间网格，与 SAM image embedding 的空间尺寸恰好对齐——这是选择 ViT-B/16 与 1024 输入的直接原因。

### 3.3.2 DPT 简化融合头：多层特征的逐步融合

单独使用 DINOv3 最后一层特征会丢失浅层的边缘与纹理信息，而分割边界质量恰恰依赖这类低层线索。我们采用一个简化的 DPT 风格融合头（`DPTHead`），从主干抽取 $K$ 个中间层的 patch token 序列 $\{F_i \in \mathbb{R}^{B \times N \times 768}\}_{i=1}^{K}$（`get_intermediate_layers`，$N = 64 \times 64$）。由于所有中间层分辨率相同（ViT 无下采样），无需 DPT 原版的重组与上采样，融合过程为：

$$
\begin{aligned}
X_i &= \mathrm{reshape}(F_i) \in \mathbb{R}^{B \times 768 \times 64 \times 64}, \\
Y_i &= \mathrm{Conv}_{3\times3}^{256 \to 256}\big(\mathrm{Conv}_{1\times1}^{768 \to 256}(X_i)\big), \quad i = 1, \dots, K, \\
Z &= \mathrm{Conv}_{1\times1}^{256K \to 768}\big([\,Y_1; Y_2; \cdots; Y_K\,]\big) \in \mathbb{R}^{B \times 768 \times 64 \times 64},
\end{aligned}
$$

即每层先经 $1\times1$ 卷积投影到 256 通道，再经无偏置的 $3\times3$ 卷积做空间精化，然后沿通道维拼接，最后用 $1\times1$ 卷积压回 768 维。融合结果重新展平为 token 序列 $(B, N, 768)$ 送入后续适配器。$3\times3$ 精化卷积的作用是在拼接前为每层特征引入局部空间上下文，弥补逐 token 投影缺少的邻域交互。

融合头支持任意层数 $K$（3、4、12 均可），且 $K=4$ 时的 state_dict 键与早期实现（`DPTSimpleHead`）逐字节一致，保证 checkpoint 向后兼容。**主配置取 `dpt_layers = 0,3,6,9`**——从第 0 层起步的等间隔采样，使融合覆盖到最浅层的低层特征；代码默认值 `2,5,8,11`（偏向中高层的等间隔采样）作为对照配置保留。

### 3.3.3 Mona 适配器：近恒等初始化的多尺度空间适配

冻结主干之后，需要一个可训练的适配结构把 DINOv3 特征"扭转"到分割任务需要的表征上。我们在 DPT 融合输出后串联两个 Mona 适配器。单个 Mona 的计算为：

$$
\begin{aligned}
x' &= \gamma \odot \mathrm{LN}(x) + \gamma_x \odot x, \\
z &= W_{\downarrow} x' \in \mathbb{R}^{B \times N \times 96}, \qquad (768 \to 768/8 = 96) \\
z' &= \mathrm{MonaOp}(z), \\
\mathrm{out} &= x + W_{\uparrow}\,\mathrm{Dropout}\big(\mathrm{GELU}(z')\big),
\end{aligned}
$$

其中缩放向量 $\gamma$ 初始化为 $10^{-6}$、$\gamma_x$ 初始化为 $1$。这一**近恒等初始化**使适配器在训练起点近似恒等映射（归一化支路的贡献几乎为零），残差主路保持原特征不变，训练从"不破坏预训练特征"的安全点出发，梯度逐渐学出需要的偏移量。

空间算子 MonaOp 在瓶颈维度上执行**多尺度深度卷积**：token 序列按 $(H, W) = (64, 64)$ 还原为 2D 特征图后，

$$
\begin{aligned}
u &= \tfrac{1}{3}\big(\mathrm{DWConv}_{3\times3}(z) + \mathrm{DWConv}_{5\times5}(z) + \mathrm{DWConv}_{7\times7}(z)\big) + z, \\
z' &= z + \mathrm{Conv}_{1\times1}(u),
\end{aligned}
$$

即 $3/5/7$ 三种感受野的 depthwise 卷积取平均并叠加恒等支路，再经 $1\times1$ 逐点卷积与第二条残差输出。多尺度设计让适配器同时捕获细粒度边界与较大范围的形状上下文，而 depthwise + 瓶颈（缩减因子 8）结构把可训练参数量压到很低。Dropout 率为 0.1。

**适配器变体。** 框架另提供两种可替换的适配器用于消融对照（`adapter_type` 选择）：

- **FC adapter**：去掉 MonaOp，仅保留 $\gamma/\gamma_x$ 缩放、瓶颈 MLP（下投影 → GELU → Dropout → 上投影）与残差，即纯通道维适配、无任何空间交互；
- **DualAttn adapter**：以 DANet 风格的 Position Attention（PAM）与 Channel Attention（CAM）并联替代瓶颈 MLP，$\mathrm{out} = x + \tfrac{1}{2}\big(\mathrm{PAM}(x) + \mathrm{CAM}(x)\big)$。两个注意力模块内部的残差被移除、只保留一条全局残差，且各自的输出缩放 $\gamma$ 初始化为 $0$——同样是"训练起点恒等"的设计。PAM 对 $N \times N$ 空间位置亲和建模（query/key 经 $1\times1$ 卷积降维，缩减因子 8），CAM 按官方 DANet 公式对 $C \times C$ 通道亲和建模（$\mathrm{energy\_new} = \max(\mathrm{energy}) - \mathrm{energy}$ 后 softmax）。

当 `adapter_type = dpt_simple`（主配置）时，DPT 融合头之后固定串联两个 Mona 适配器；`dpt_layers` 参数仅在此模式下合法，其他组合在构造期即抛出 `ValueError`，防止配置被静默忽略。

### 3.3.4 到 SAM 表征空间的线性投影

适配后的 768 维 token 经单层线性投影降到 256 维，再重排为 $(B, 256, 64, 64)$——与 SAM image encoder 的输出形状与语义位置完全一致。这样，SAM 的 prompt encoder、mask decoder 以及我们新增的 depth 分支都可以不加修改地消费该 embedding。编码器返回 `(image_embeddings, input_size)`，其中 `input_size = (1024, 1024)` 供后续掩码后处理使用。

## 3.4 Mask 分支

Mask 分支复用 SAM ViT-B 的 prompt encoder 与 mask decoder（从官方 checkpoint 初始化），负责把点提示（以及可选的上一轮低分辨率掩码）解码为分割结果。

**逐样本坐标变换。** 点提示坐标定义在各自样本的原始图像空间中，而 batch 内各样本原始尺寸不同，因此坐标变换（`ResizeLongestSide.apply_coords_torch`，映射到最长边 1024 的模型输入空间）必须逐样本执行，变换后再拼回 batch。

**批量 prompt encoder、逐样本 mask decoder。** SAM 的 `PromptEncoder` 对 batch 输入是安全的，故一个 batch 只调用一次；但 `MaskDecoder.predict_masks` 内部使用 `repeat_interleave` 把 image embedding 沿 batch 维按 token 数复制——当输入本身是 $B > 1$ 的 batch 时会产生 $B^2$ 规模的张量并错乱样本对应关系。因此 mask decoder 以逐样本循环方式调用，每次处理一个样本的 embedding 与提示。这一"编码批量、解码逐样本"的折衷在保证正确性的同时尽可能保留了批量并行。

**单掩码模式。** 解码固定使用 `multimask_output=False`：本任务中每幅图只有一个目标真值，多假设输出没有监督信号可以区分，单掩码模式还能让 IoU 预测头专注校准唯一输出。解码得到低分辨率掩码 logits（$256 \times 256$）与 IoU 预测 $\hat{u} \in \mathbb{R}^{B \times 1}$。

**可跳过的全分辨率后处理。** 低分辨率掩码经 `postprocess_masks`（去 padding、上采样回各自 `original_size`）得到全分辨率 logits；由于各样本原始尺寸不同，该步骤同样逐样本进行。`forward_mask` 提供 `return_fullres` 开关：在 phase 2 中 mask 分支已冻结、其输出仅在日志批次上需要评估时，非日志批次跳过全分辨率上采样以节省显存与计算。

另外，模型侧的图像预处理绕开了 SAM 自带的 `apply_image_torch`（上游实现用张量的第 0、1 维而非 2、3 维计算缩放目标，属于已知缺陷），自行实现"最长边缩放 → 归一化 → 右下 padding 到 $1024^2$"（该路径服务于 `encoder_type="sam"` 的对照配置；DINOv3 路径使用 3.3.1 节的方形缩放预处理）。

## 3.5 Depth 分支

Depth 分支的设计原则是**最大限度复用 SAM 的解码机制**：既然 SAM 的 mask decoder 已经证明了"prompt token 与图像特征做双向注意力、再由输出 token 读出预测"这一范式的有效性，深度回归完全可以套用同一范式——只需把读出的目标从 IoU 换成深度。

### 3.5.1 Outer prompt encoder 与 depth-mask decoder

Depth 分支拥有一个独立的 `outer_prompt_encoder`，结构与 SAM prompt encoder 完全相同（embed_dim 256、mask 输入通道 16）。它接收两类条件：

- **稠密条件**：mask 分支输出的低分辨率掩码 logits（$256 \times 256$），经其 mask 下采样卷积编码为稠密 embedding 叠加到图像特征上——这是"深度以掩码为条件"的实现载体；
- **稀疏条件**：可选的深度分支点提示（训练时由迭代过程产生，见 3.6.3 节），坐标同样逐样本经 `apply_coords_torch` 变换后批量编码。

核心解码器 `DepthMaskDecoder` 与 SAM `MaskDecoder` 同构，差异有四处：

1. **depth token 替换 IoU token**：输出 token 序列为 $[\,t_{\text{depth}};\ t_{\text{mask}};\ \text{sparse prompts}\,]$，其中 $t_{\text{depth}}$ 是一个可学习 embedding，占据 SAM 中 IoU token 的位置；
2. **单 mask token**：只保留 1 个 mask token（SAM 有 4 个），无 multimask 逻辑；
3. **辅助掩码输出**：mask token 经过 transformer 后，由超网络 MLP 生成动态权重 $\omega = \mathrm{MLP}_{\text{hyper}}(t_{\text{mask}}^{\text{out}}) \in \mathbb{R}^{32}$，与两级转置卷积上采样（$64 \to 256$，通道 $256 \to 64 \to 32$）后的图像特征 $U \in \mathbb{R}^{32 \times 256 \times 256}$ 做**内积**得到辅助掩码 logits：$\hat{M}_{\text{aux}} = \omega \cdot U$。该掩码不用于最终分割输出，其作用是（a）为 depth 分支提供显式的空间监督通路，（b）在迭代训练中充当误差点采样的依据（3.6.3 节）；
4. **3 层深度 MLP**：depth token 的输出经 $\mathrm{MLP}(256 \to 256 \to 256 \to 1)$（3 层，隐藏维 256）回归标量深度 $\hat{d}$。

形式化地，一次深度解码为：

$$
\begin{aligned}
(h, \tilde{E}) &= \mathrm{Transformer}\big(E + \mathrm{Dense}(\hat{M}_{\text{low}}),\ \mathrm{PE},\ [\,t_{\text{depth}}; t_{\text{mask}}; S\,]\big), \\
\hat{d} &= \mathrm{MLP}_{\text{depth}}(h_0), \qquad
\hat{M}_{\text{aux}} = \mathrm{MLP}_{\text{hyper}}(h_1) \cdot \mathrm{Upscale}(\tilde{E}),
\end{aligned}
$$

其中 $E$ 为共享 image embedding，$S$ 为稀疏提示 embedding，$h_0, h_1$ 分别为 depth token 与 mask token 的输出状态。与 mask 分支同理，`DepthMaskDecoder` 内部含 `repeat_interleave`，故解码逐样本执行、outer prompt encoder 批量执行；辅助掩码逐样本 `postprocess_masks` 回原始分辨率。

### 3.5.2 Mask 条件化的 detach / 冻结语义

Depth 分支消费 mask 分支的输出，但两者的梯度必须隔离，否则深度损失会通过低分辨率掩码反向"污染"mask 分支，损害已训练好的分割质量。隔离通过两重机制实现：

- **detach**：在联合前向（`forward`）、phase 2 验证与最终评估中，`low_res_masks` 一律 `detach()` 后再送入 outer prompt encoder；
- **冻结**：在 phase 2 训练中，mask 分支（SAM prompt encoder + mask decoder）与图像编码路径全部冻结（3.8 节），即便迭代训练路径中掩码张量未显式 detach，梯度也不会更新任何 mask 分支参数。

两重语义共同保证：**深度监督只塑造 depth 分支自身，掩码质量完全由 phase 1 决定**。

### 3.5.3 SAM 权重的结构感知初始化

Depth 分支若从随机初始化出发，需要独自学会"注意力读图"的全部技能。由于其结构与 SAM 解码通路逐模块对应，我们在构造后执行一次结构感知的权重迁移（`init_depth_from_sam`），映射表如下：

| depth 分支模块 | 来源（SAM 内层权重） | 说明 |
|---|---|---|
| `outer_prompt_encoder` | `sam.prompt_encoder` | 结构完全相同，整体拷贝 |
| `depth_decoder.transformer` | `mask_decoder.transformer` | 键名相同逐一拷贝；**dual_attn 变体跳过**（结构不同，保持随机初始化） |
| `depth_token` | `mask_decoder.iou_token` | 形状相同；IoU token 与 depth token 同为"读出全局标量"的角色 |
| `mask_tokens` | `mask_decoder.mask_tokens[0]` | 取 SAM 4 个 mask token 中的第一个 |
| `output_upscaling` | `mask_decoder.output_upscaling` | 结构相同，整体拷贝 |
| `output_hypernetworks_mlps[0]` | `mask_decoder.output_hypernetworks_mlps[0]` | 取第一个超网络 MLP |
| `depth_prediction_head` | —（保持随机初始化） | SAM 中无对应结构 |

该初始化使 depth 分支从"已会分割读图、只差学会读深度"的起点开始训练，唯一的新知识集中在随机初始化的 3 层深度 MLP 上。

### 3.5.4 深度 transformer 的三种变体

depth 分支的 transformer 由 `depth_transformer_type` 选择，构成一组消融谱系：

- **TwoWay（主配置）**：SAM 原生 `TwoWayTransformer`（depth 2、embed 256、MLP 2048、8 头），可完整承接 3.5.3 节的权重迁移；
- **DualAttn**：结构对标 TwoWayTransformer，但把每层第一步的 token self-attention 替换为对图像特征的 PAM + CAM 增强（`keys + PAM(keys) + CAM(keys)` 残差后 LayerNorm，两个 $\gamma$ 自学、不做平均），其余的 token→image cross-attention、token MLP、image→token cross-attention 与最终 attention 层保持一致。因结构差异，transformer 部分不做 SAM 权重迁移、从随机初始化训练；
- **Simple（池化下界基线）**：完全绕开 prompt encoder 与解码器，直接对 image embedding 做全局平均池化后过 MLP（$256 \to 1024 \to 256 \to 1$）回归深度。该变体不接收任何掩码或点条件，用于回答"不做目标条件化、只看全图特征能把深度回归到什么程度"，作为条件化设计收益的下界参照。

## 3.6 迭代式训练

交互式分割的部署形态是"用户看到结果、在错误处点击、模型修正"的闭环。若训练时只用初始提示做单次前向，模型从未见过"带修正点击的提示分布"，推理时的多轮交互就成为分布外输入。为此，两个训练阶段都采用**在线模拟用户点击的迭代式训练**（借鉴 micro-sam 的迭代范式），主配置每步迭代 $T = 8$ 个子轮次。

### 3.6.1 误差点采样器

迭代的核心是从"预测 vs 真值"的差异中采样新点击（`DepthIterativePromptGenerator`）。记二值化预测为 $\hat{M}$、真值为 $G$，误差图 $\Delta = \hat{M} - G$ 划分出两类区域：漏检前景（$\Delta = -1$，需要正点）与误检背景（$\Delta = +1$，需要负点）。每幅图每轮采 **1 正 + 1 负** 两个点，均在对应区域内均匀随机采样。为保证任何退化情形下都能产出合法点，正负点各配备一条完整的 fallback 链：

- **正点**：漏检前景区域 → （若为空）预测与真值的重叠区 → （仍为空）任意真值前景 → （真值全空）图像中心；
- **负点**：误检背景区域 → （若为空）目标包围盒外扩 3 像素范围内的背景（模拟用户在目标边界附近点背景的习惯性行为）→ （仍为空）任意背景 → （全图无背景）坐标原点 $(0,0)$。

采样在 $256 \times 256$ 低分辨率网格上进行（真值以最近邻下采样、预测按 logits $> 0$ 二值化），采出的坐标按各样本原始尺寸线性缩放回原图空间，再交由 `forward_mask` / `forward_depth` 内部的逐样本坐标变换处理。

### 3.6.2 Phase 1：mask 分支的迭代精化循环

Phase 1 每个训练步（`iterative_mask_step`）的流程如下。**图像编码在整个步内只执行一次**——8 个子轮次共享同一份 image embedding，既节省了最昂贵的主干前向，也保证各轮解码建立在一致的特征上：

```
image_embeddings ← encode(I)                     # 仅一次
P ← 数据集质心提示;  mask_input ← None
for t = 1 … T:
    M̂_low, û, M̂_full ← forward_mask(E, P, mask_input)
    累加 L_dice(M̂_full, G) 与 L_iou(û, IoU(M̂_full, G))   # 每轮都回传监督
    if t < T:
        (p⁺, p⁻) ← 误差点采样(G↓, 1[M̂_low > 0])          # no_grad
        P ← P ∪ {p⁺, p⁻}                                  # 提示单调累积
        mask_input ← M̂_low.detach()  以概率 p_mask = 0.5
                     None            否则
loss = (1/T)Σ L_dice + (1/T)Σ L_iou;  一次 backward + step
```

三个设计点需要说明：

1. **提示单调累积**：新点击只追加、从不替换，与真实交互中"历史点击始终有效"的语义一致；到第 $T$ 轮时提示集合含初始质心点加 $2(T-1)$ 个修正点。
2. **$p_{\text{mask}} = 0.5$ 的随机掩码回传**：每轮以 0.5 的概率把上一轮的低分辨率掩码 logits（detach 后）作为 `mask_input` 送回 prompt encoder，否则不送。SAM 推理时既可能携带上一轮掩码也可能只有点击，随机化使模型对两种条件都鲁棒，避免解码器过度依赖掩码先验。
3. **逐轮监督、一次回传**：8 个子轮次的 Dice 与 IoU 损失取平均后做一次反向传播。每一轮（而非仅最后一轮）都有监督，迫使模型在提示很少时也给出尽量好的结果，即学习整条"从粗到精"的交互轨迹；采点与掩码回传均在 `no_grad` 下进行，梯度不会穿过离散的采样决策。

### 3.6.3 Phase 2：depth 分支的迭代循环与"仅掩码 → 密集点击"课程

Phase 2 每个训练步（`iterative_depth_step`）中 mask 分支已冻结，迭代对象换成 depth 分支：

```
image_embeddings ← encode(I)                     # 仅一次
M̂_low ← forward_mask(E, 数据集质心提示)          # mask 分支只跑一次
P_d ← ∅                                          # 深度提示从空集出发
for t = 1 … T:
    d̂_t, M̂_aux ← forward_depth(E, M̂_low, P_d)
    累加 L_depth = MSE(d̂_t, d) 与 L_aux-dice(M̂_aux, G)   # 后者仅诊断
    if t < T:
        (p⁺, p⁻) ← 误差点采样(G↓, 1[M̂_aux↓ > 0])         # 由辅助掩码误差驱动
        P_d ← P_d ∪ {p⁺, p⁻}
loss = λ_d · (1/T)Σ L_depth;  一次 backward + step
```

与 phase 1 的关键差异及其动机：

1. **mask 分支只前向一次**：mask 分支已冻结，其输出对本步恒定，重复计算毫无收益；固定的 $\hat{M}_{\text{low}}$ 作为全部子轮次共享的稠密条件。
2. **深度提示从空集出发**：第 1 个子轮次 `forward_depth` 不带任何点提示（`points=None`），深度预测完全依赖掩码条件——这正对应最终推理时"仅以掩码单次查询深度"的形态（3.10 节）；随后各轮逐步累积点击。这样，一个训练步内部天然构成一条 **"仅掩码 → 稀疏点击 → 密集点击"的课程**：模型既学会零点击下的深度读出，也学会利用更多空间线索修正预测。
3. **采点由辅助掩码误差驱动**：新点击不是从冻结的 mask 分支输出、而是从 depth 分支自己的辅助掩码 $\hat{M}_{\text{aux}}$（全分辨率输出经双线性下采样到 $256^2$、按 logits $> 0$ 二值化）与真值的差异中采出。动机在于：点提示应指向 *depth 分支自身* 对目标空间范围理解的薄弱处，让点击成为对该分支注意力的定向修正，而非重复 mask 分支已有的信息。
4. **辅助掩码 Dice 仅作诊断**：每轮计算 $\hat{M}_{\text{aux}}$ 对真值的 Dice 并记录，但**不计入总损失**——phase 2 的优化目标只有深度 MSE。辅助掩码通过采点机制间接影响训练，其数值仅用于监控 depth 分支的空间对齐程度。同样，mask 分支输出的 Dice 也只作日志观察。

两阶段均保留非迭代退化路径（`n_sub_iterations = 1` 时单次前向、单次回传），主配置不使用。

## 3.7 损失函数

### 3.7.1 分割：Dice 损失

分割主损失为软 Dice。对全分辨率掩码 logits $\hat{M}$，令 $\hat{p} = \sigma(\hat{M})$，

$$
\mathcal{L}_{\text{dice}} = 1 - \frac{1}{B} \sum_{b=1}^{B} \frac{2 \sum_{h,w} \hat{p}_b \, G_b + \varepsilon}{\sum_{h,w} \hat{p}_b + \sum_{h,w} G_b + \varepsilon}, \qquad \varepsilon = 10^{-6}.
$$

Dice 对前景占比小的目标不敏感于类别不平衡，适合本数据中目标尺度差异较大的场景。

### 3.7.2 IoU 回归：对 stop-grad 真实 IoU 的 MSE

SAM 的 IoU 预测头输出 $\hat{u}$，其监督目标为当前预测掩码与真值的**真实 IoU**：

$$
u^\star = \frac{|\,\mathbb{1}[\sigma(\hat{M}) > 0.5] \cap G\,|}{|\,\mathbb{1}[\sigma(\hat{M}) > 0.5] \cup G\,|}, \qquad
\mathcal{L}_{\text{iou}} = \mathrm{MSE}(\hat{u}, u^\star).
$$

$u^\star$ 在 `torch.no_grad()` 下计算（stop-gradient）：它是"标签"而非可优化量，若允许梯度流入，模型可以通过恶化掩码本身来缩小预测误差，与校准目标背道而驰。该损失使 IoU 头成为可信的自评估器，其校准质量在评估阶段以 IoU 校准 MAE 度量（3.10 节）。

### 3.7.3 可选的边界带 Dice（主配置关闭）

为改善掩码边缘的锯齿问题，框架提供可选的边界感知损失（`--boundary_loss` 开关，**主配置关闭**）。真值的内边界带由形态学腐蚀构造：以核宽 $k = 2w + 1$（$w$ 为带半宽，默认 3）的最小池化（$-\mathrm{maxpool}(-G)$）得到腐蚀图 $G_{\text{ero}}$，边界带 $B_G = G - G_{\text{ero}}$。损失为仅在边界带上计算的 Dice：

$$
\mathcal{L}_{\text{bd}} = 1 - \frac{1}{B}\sum_b \frac{2\sum (\hat{p}_b B_{G,b})(G_b B_{G,b}) + \varepsilon}{\sum \hat{p}_b B_{G,b} + \sum G_b B_{G,b} + \varepsilon},
$$

启用时以权重 $\lambda_{\text{bd}}$（默认 1.0）并入掩码损失。

### 3.7.4 深度：MSE

深度损失为归一化尺度上的均方误差：

$$
\mathcal{L}_{\text{depth}} = \mathrm{MSE}(\hat{d}, d) = \frac{1}{B}\sum_b (\hat{d}_b - d_b)^2 .
$$

### 3.7.5 阶段总目标、梯度归属与模型选择

记 $T$ 为子轮次数（主配置 8），各轮损失以上标 $t$ 标记：

$$
\mathcal{L}_{\text{phase1}} = \frac{1}{T}\sum_{t=1}^{T}\Big(\mathcal{L}_{\text{dice}}^{(t)} + \lambda_{\text{bd}}\,\mathcal{L}_{\text{bd}}^{(t)}\Big) + \frac{1}{T}\sum_{t=1}^{T} \mathcal{L}_{\text{iou}}^{(t)}, \qquad
\mathcal{L}_{\text{phase2}} = \lambda_d \cdot \frac{1}{T}\sum_{t=1}^{T} \mathcal{L}_{\text{depth}}^{(t)},
$$

主配置下 $\lambda_{\text{bd}}$ 项关闭、$\lambda_d = 1$。**只做诊断、不产生梯度的量**包括：真实 IoU $u^\star$（stop-grad 标签）、phase 2 中辅助掩码的 Dice、phase 2 中 mask 分支输出的 Dice（且仅在日志批次上计算全分辨率掩码）。

**验证准则与模型选择**：验证一律走非迭代路径、只用数据集质心提示。Phase 1 的验证损失为 $\mathcal{L}_{\text{dice}} + \mathcal{L}_{\text{iou}}$（若启用则加边界项）；phase 2 的验证损失为 $\lambda_d \mathcal{L}_{\text{depth}}$，其中深度提示取数据集质心点、掩码条件取 detach 后的 mask 分支输出。各阶段以验证损失最小者保存为该阶段的 best checkpoint。

## 3.8 两阶段训练协议

### 3.8.1 冻结 / 可训练组件对照

| 组件 | Phase 1（分割） | Phase 2（深度） |
|---|---|---|
| DINOv3 backbone | 冻结 | 冻结 |
| DPT head / Mona adapter ×2 / projection | **可训练** | 冻结 |
| SAM prompt encoder | **可训练** | 冻结 |
| SAM mask decoder | **可训练** | 冻结 |
| outer prompt encoder | 冻结 | **可训练** |
| depth-mask decoder（含 depth MLP） | 冻结 | **可训练** |
| （simple 变体）simple_depth_head | 冻结 | **可训练** |

Phase 1 通过 `freeze_image_encoder()`（冻结 DINOv3 主干与 SAM 原生 image encoder）+ `freeze_depth_branch()` 实现；phase 2 先把全部参数置为不可训练，再单独解冻 depth 分支两模块（simple 变体则解冻 `simple_depth_head`）。

### 3.8.2 解耦的两点理由

为什么不端到端联合训练？

1. **梯度污染**：分割与深度共享编码路径与掩码接口。联合训练时深度 MSE 的梯度会经共享模块冲刷分割表征，二任务的梯度方向没有理由一致，分割质量可能被牺牲；两阶段划分配合 3.5.2 节的 detach/冻结语义，使每类监督只塑造自己的分支。
2. **条件分布平稳性**：depth 分支以 mask 分支的输出为条件输入。若两分支同时训练，深度所面对的掩码条件分布随分割分支的更新持续漂移，等价于在非平稳输入上回归。先把分割训练收敛并冻结，phase 2 的 depth 分支面对的是平稳的掩码分布，学习问题更良置。

### 3.8.3 优化器、checkpoint 与断点续训

两阶段各自新建 AdamW 优化器（学习率 $10^{-5}$，仅收集 `requires_grad=True` 的参数）与 StepLR 调度器（每 10 个 epoch 学习率减半），各训练 50 个 epoch。每阶段维护**三路 checkpoint**：

- `phase{1,2}_best.pt`：验证损失最优模型（用于评估与阶段衔接）；
- `phase{1,2}_last.pt`：每个 epoch 覆盖写入，含 model/optimizer/scheduler 状态、epoch 号、最优验证损失与 `adapter_type` 元数据，`--resume` 时从此恢复断点续训；
- `phase{1,2}_epoch_N.pt`：每 `save_interval`（10）个 epoch 的周期性快照。

Phase 2 启动时加载 phase 1 的 best checkpoint（`strict=False`，兼容跨 `adapter_type` 加载并自动重映射旧版 `mona1/mona2` 键名到 `adapter1/adapter2`），随后**重新执行一次 `init_depth_from_sam`**：phase 1 期间 depth 分支冻结未训练，重新初始化确保 phase 2 从干净的 SAM 先验（而非任何中间状态）出发。若 checkpoint 记录的 `adapter_type` 与当前配置不符则打印告警。

## 3.9 双 DPT 层解耦扩展

3.3 节的编码器为两个分支输出**同一份** image embedding，隐含假设"分割与深度偏好相同的中间层组合"。但两任务对层位的需求未必一致：分割依赖边界敏感的浅中层特征，深度这类整体属性可能更受益于高层语义。为此我们设计了双 DPT 层解耦扩展（已通过评审的设计规格，作为方法的组成部分在此给出），允许 mask 分支与 depth 分支各用一组独立的 `dpt_layers` 构建各自的 embedding。

**开关与校验。** 新增 CLI 参数 `--dpt_layers_depth`；提供该参数即启用双头模式，原 `--dpt_layers` 退化为 mask 分支专属配置。参数无条件解析并在 CLI 层立即校验：与 `encoder != dinov3` 或 `adapter_type != dpt_simple` 组合直接报错退出（不得静默忽略——`--encoder sam` 时编码器不会被构造，encoder 侧校验够不到）；两组层索引各自必须严格升序且无重复（backbone 的 `get_intermediate_layers` 恒按块索引升序返回，乱序配置会造成层与权重错位）。encoder 侧保留防御性 `ValueError`。

**Union 单次前向 + 索引分发。** 双头模式下 backbone 仍**只前向一次**：取两组层的并集 $\mathcal{U} = \mathrm{sorted}(\mathcal{L}_{\text{mask}} \cup \mathcal{L}_{\text{depth}})$ 一次性抽取中间特征，再由模块级纯函数 `split_union_features` 按索引把特征分发给两组配置——重叠层的特征被两个分支共享读取而不重复计算。

**分支独立编码流。** 每个分支拥有独立的一套后端：mask 分支沿用原模块名（`dpt_head` / `adapter1` / `adapter2` / `projection`），depth 分支新增 `dpt_head_depth` / `adapter1_depth` / `adapter2_depth` / `projection_depth`。`encode_images` 在双头模式下返回 `{"mask": E_m, "depth": E_d}` 字典；`forward_mask` / `forward_depth` 的函数体第一条语句做 `isinstance(dict)` 分支选择、各取所需 embedding，全部既有调用点零改动。mask 分支保留原参数名是向后兼容的关键：开关关闭时模型结构与 state_dict 键和现状逐字节一致，旧单头 checkpoint 在双头模式下经 `strict=False` 自动装入 mask 分支。

**按阶段冻结 / 解冻。** 若不改冻结逻辑，`*_depth` 编码模块将永远得不到训练（设计评审发现的关键缺口）。语义定为：phase 1 中四个 `*_depth` 模块随 depth 分支一并冻结（`freeze_depth_branch` 扩展），消除梯度与激活保存开销；phase 2 中随 outer prompt encoder、depth decoder 一并解冻。phase 2 中 mask 分支的编码模块维持冻结。已接受的代价是 phase 1 双头模式会多算一份 depth 侧编码前向（相对 12 层 ViT 主干开销小于 5%）。

**Warm-start 语义。** phase 2 加载 phase 1 checkpoint 后，无条件执行 `warm_start_depth_branch()`：把 mask 分支训练好的 `adapter1/adapter2/projection` 权重拷贝到对应的 `*_depth` 模块，让 depth 侧编码流从"已适配好的特征变换"出发；而 **`dpt_head_depth` 恒保持随机初始化、不拷贝**——理由是该特性的动机场景就是两分支层数不同，DPT head 的权重形状随层数变化，同层数拷贝在真实用法中几乎不触发（评审采纳的 YAGNI 裁剪）。之所以"无条件"执行而不依赖 missing_keys 判断：phase 1 从不训练 `*_depth` 模块，即使双头 phase 1 checkpoint 存有这些键也只是随机初值，覆盖拷贝恒正确（双头 phase 1 产物的 missing_keys 为空，条件触发会失效）。评估侧不做 warm-start（评估不训练，随机 depth 编码流的输出无意义）。

**跨模式加载报错。** checkpoint 新增保存 `dpt_layers` / `dpt_layers_depth` 元数据。跨模式组合一律显式报错而非静默降级：单头模式加载双头 checkpoint（unexpected_keys 含 `dinov3_encoder.` 前缀的 `*_depth` 模块键）→ 提示补 `--dpt_layers_depth`，防止 depth decoder 拿 mask embedding 安静地输出错误深度；双头模式 resume 旧单头 `last.pt` → 报错（optimizer param_groups 数量不匹配，续训必然崩溃），提示从 phase 1 checkpoint 重新 warm-start；双头模式评估单头 checkpoint → 报错并提示去掉开关或换 checkpoint。`*_depth` 键检测按 `dinov3_encoder.` 前缀加四个模块名精确匹配，不用子串包含（`simple_depth_head` 也含 `_depth`，子串匹配会误伤）。

## 3.10 推理与评估

### 3.10.1 Oracle 用户模拟的迭代评估

评估复现训练时的交互形态：以数据集质心点为初始提示，迭代 `n_sub_iterations` 轮，每轮由 3.6.1 节的误差点采样器根据"当前预测 vs 真值"产生 1 正 1 负修正点并累积（可选地以概率 `mask_prob` 回传上一轮低分辨率掩码，评估默认 0）。由于采点需要真值参与，这一协议是 **oracle 用户模拟**——它度量的是"每次点击都准确指向错误区域的理想用户"与模型协作能达到的性能上界。我们报告单点击（$T=1$）与多轮交互（$T=8$）两种设定。

### 3.10.2 深度的单次查询

迭代结束后，深度**仅以最终掩码做单次查询**：`forward_depth` 只接收 detach 后的最终低分辨率掩码作为条件，**不传任何深度点提示**。该设定与 phase 2 训练课程的起点（"仅掩码"轮次）一致，代表部署中最自然的形态——用户完成分割交互后，深度作为该目标的属性一次性读出。

### 3.10.3 指标

分割指标逐样本计算后取均值与中位数（预测按 $\sigma > 0.5$ 二值化）：

- **Dice**、**IoU**：区域重叠度；
- **Boundary IoU**：预测与真值各自的内边界带（腐蚀半宽 2 像素，`mask − erode(mask)`）之间的 IoU，专门度量边缘质量；
- **Precision / Recall**：误检与漏检的分解视角；
- **IoU 校准 MAE**：$\mathrm{mean}\,|\hat{u} - u^\star|$，度量 IoU 预测头的自评估可信度。

深度指标在原始尺度（$\times 100$）上报告：**MAE、MSE、RMSE、$R^2$**（$R^2 = 1 - \mathrm{SS}_{\text{res}} / \mathrm{SS}_{\text{tot}}$），并附预测与真值的均值/标准差。此外提供两类细粒度分析：

- **按类分解**：按深度类别（目录）分别统计 MAE、RMSE、预测均值与样本数，暴露误差随深度真值的分布（例如极值类是否系统性回归到均值）；
- **散点分析**：预测–真值散点图（对照 $y = x$）与残差–真值散点图（对照 $y = 0$），可视化系统性偏差与异方差。

评估脚本同时输出 phase 1 模型（仅分割训练）与 phase 2 模型的全部指标及逐项对比，验证 phase 2 训练未损害分割性能（由冻结语义保证，此处做经验确认）；可选保存逐样本的预测/真值掩码图。

### 3.10.4 PCA 特征分析

为定性检查"DPT 各层特征学到了什么、融合是否有效"，我们提供 PCA 特征可视化：对每个 DPT 中间层的 token 特征以及融合头拼接后的特征（`return_fused` 通路），逐样本做 3 主成分白化 PCA，投影经 sigmoid（增益 2.0）映射为 RGB 图。支持前景约束模式——PCA 仅在掩码前景 token 上拟合（前景为空时回退全图拟合），再投影全图并置黑背景，使主成分方向由目标本身而非背景主导。该分析有两个挂载点：（a）**验证期挂载**（`--pca_viz`）：每 `pca_interval` 个 epoch 对固定的首个验证批次（validation loader 不 shuffle，故样本恒定）生成可视化，用于观察训练过程中特征的演化；（b）独立 CLI（`pca_viz.py`）：对任意推理图像生成可视化，可选用模型自身以图像中心点提示预测的掩码作为前景约束。

## 3.11 实现细节

**主配置超参数汇总**：

| 项 | 值 |
|---|---|
| encoder / adapter | DINOv3 ViT-B/16（冻结）+ dpt_simple + Mona ×2 |
| dpt_layers | 0, 3, 6, 9（对照：2, 5, 8, 11） |
| depth transformer | TwoWay（depth 2，embed 256，MLP 2048，8 头） |
| 输入分辨率 / patch 网格 | $1024 \times 1024$ / $64 \times 64$ |
| 训练阶段 | both（phase 1 → phase 2），每阶段 50 epoch |
| batch size / 学习率 | 8 / $10^{-5}$ |
| 优化器 / 调度 | AdamW / StepLR（每 10 epoch × 0.5） |
| 迭代子轮次 $T$ / $p_{\text{mask}}$ | 8 / 0.5 |
| max_points / 深度损失权重 $\lambda_d$ | 3 / 1.0 |
| boundary loss | 关闭 |
| Mona 瓶颈因子 / dropout | 8（768→96）/ 0.1 |
| 数据 | 0_sam_train 1345 样本 / 0_sam_test 343 样本 |

**可训练参数构成**：phase 1 训练 DPT head、两个 Mona 适配器、线性投影、SAM prompt encoder 与 mask decoder；phase 2 仅训练 outer prompt encoder 与 depth-mask decoder。DINOv3 主干（约 86M 参数）全程冻结。

**数据增强**：**无**。训练与评估使用完全相同的确定性预处理（缩放 + 归一化），不做翻转、裁剪、颜色扰动等任何增强。

**随机性来源**：（1）训练 DataLoader 的 shuffle；（2）误差点在误差区域内的均匀随机采样（`np.random.choice`）；（3）掩码回传的伯努利决策（`random.random() < p_mask`）；（4）适配器中的 dropout；（5）depth prediction head 等未迁移权重的随机初始化。验证与评估路径除误差点采样（仅迭代评估）外均为确定性。

**工程细节**：mask decoder 与 depth decoder 因 SAM 实现中的 `repeat_interleave` 语义按逐样本循环调用，prompt encoder 保持批量调用（3.4 节）；模型侧预处理绕开上游 SAM `apply_image_torch` 的尺寸计算缺陷；checkpoint 加载统一经过旧版 `mona1/mona2 → adapter1/adapter2` 键名重映射并以 `strict=False` 兼容跨配置加载；训练日志经 TensorBoard 记录逐步损失曲线。
