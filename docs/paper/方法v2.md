# Method

## 1 问题形式化：三维细胞定位

本文任务是三维空间中的细胞定位：给定一张显微镜图像 $I \in \mathbb{R}^{H \times W \times 3}$ 和一个用户指定的点击点 $(x, y)$，同时输出该点击所指示细胞的二值分割掩码（二维定位）及其相对焦平面的离焦深度（第三维定位）。将深度定义 $z \in [-100, 100]$ 表示细胞距物镜焦平面的有符号距离（单位 μm，负值表示高于焦平面），则三维定位可形式化为一个条件联合预测问题：

$$
(\hat{M}, \hat{z}) = \mathcal{F}(I \mid x, y)
$$

其中 $\hat{M} \in \{0, 1\}^{H \times W}$ 为预测的二值分割掩码，$\hat{z} \in \mathbb{R}$ 为预测的归一化深度值。这一形式化将三维定位问题自然地映射到"分割 + 深度回归"的端到端框架中。

**为何需要用 Mask 引导深度推理。** 显微图像中不同区域对应的离焦深度随场景变化：同一张图像中聚焦和离焦的细胞具有不同的深度标签。若仅凭一个稀疏的点击坐标直接回归全局深度，模型缺乏必要的空间约束——它无法判别"点击点所在的区域边界在哪里"，也就无法确定应该对图像中哪一块区域做深度估计。而分割掩码精确地提供了这一空间上下文：它告诉模型"这是被点击选中的细胞"，从而将深度回归从全局歧义问题转化为区域条件回归问题。因此，将掩码作为深度分支的一种稠密空间提示（dense prompt）是方法论上的自然选择。

## 2 整体架构

本文在 Segment Anything Model（SAM）\cite{sam} 的基础上构建了一个双分支模型 **DepthSam**，核心设计包括三项：

1. **编码器替换**：用冻结的 DINOv3 ViT-B/16 \cite{dinov3} 替换 SAM 的图像编码器，以获取更丰富的语义特征表示；
2. **特征适配**：通过轻量级 adapter 将 DINOv3 的 768 维特征空间对齐到 SAM mask decoder 所需的 256 维接口；
3. **Mask 引导的深度解码**：将 SAM 的 TwoWayTransformer 复用为深度解码器的核心，接收掩码分支输出的低分辨率掩码作为稠密提示，通过双向交叉注意力实现掩码条件化的深度回归。

整体前向流程如下（`dinosam/model/depth_sam.py`：`DepthSam.forward`）：

```
输入图像 (B,3,H,W)
    │
    ├─ DINOv3 Encoder (frozen) ──→ image_embeddings (B,256,64,64)
    │
    ├─[Mask Branch]──────────────────────────────────
    │   SAM prompt_encoder + mask_decoder
    │   → low_res_masks (B,1,256,256)  ──detach──┐
    │   → masks (B,1,H,W)                         │
    │                                              │
    ├─[Depth Branch]────────────────────────────────┐
    │   outer_prompt_encoder(masks=low_res_masks)   │
    │   → sparse_emb + dense_emb                    │
    │   DepthMaskDecoder (TwoWayTransformer)        │
    │   → depth_pred (B,), decoder_masks (B,1,H,W)  │
    └───────────────────────────────────────────────┘
```

掩码分支和深度分支共享同一个编码器特征图（`image_embeddings`），但各自拥有独立的提示编码器和解码器。关键的设计选择在于：掩码分支输出的低分辨率掩码被 `detach()` 后注入深度分支的 outer prompt encoder，作为 mask prompt 参与 TwoWayTransformer 的交叉注意力——这使得深度预测显式取决于"哪些区域属于被选中的细胞"，同时阻断深度梯度回传至掩码分支，保证训练稳定性。

## 3 DINOv3 编码器替换与特征适配

### 3.1 动机

SAM 的原生图像编码器（ViT-B）为通用分割任务训练，其特征表示偏向于物体边界和区域连通性。对于显微镜下细胞这种结构相对简单、纹理有限的目标，SAM 编码器的表达能力过剩，但其对离焦程度、纹理变化的感知能力不足——这些恰恰是需要深度回归建模的视觉线索。DINOv3 的自监督预训练特征蕴含更丰富的中层语义（纹理、形状、局部结构），更适应显微场景。用 DINOv3 替换 SAM 编码器时，采样逐像素视觉提示的方法必须确保推理灵活、可迁移化且无需重训练骨干网络。

DINOv3 ViT-B/16 骨干网络被完全冻结（`dinosam/model/dinov3_encoder.py:68-69`），仅 adapter 和投影层参与训练。输入图像尺寸为 $1024 \times 1024$，patch size 16，输出 $64 \times 64$ 的 patch token 序列，每个 token 维度为 768。DINOv3 backbone 的前向分两条路径（`dinov3_encoder.py:121-138`）：

- **单层路径**（`adapter_type != "dpt_simple"`）：仅取 backbone 最后一层的归一化 patch token，形状 $(B, 4096, 768)$；
- **DPT 多层融合路径**：调用 `backbone.get_intermediate_layers` 提取指定中间层特征（第 25-126 行），经 DPT 头融合为统一的 $(B, 768, 64, 64)$ 特征图，再展平为 token 序列。

### 3.2 Adapter 设计

DINOv3 的 768 维特征与 SAM mask decoder 的 256 维 prompt embedding 接口不兼容，需要 adapter 进行维度对齐和特征适配。所有 adapter 均采用**双层串联**结构（`adapter1 → adapter2`，`dinov3_encoder.py:133-134`），每个 adapter 为残差瓶颈模块，瓶颈宽度为 `in_dim // 8 = 96`。后接线性投影 `nn.Linear(768, 256)` 输出 $(B, 256, 64, 64)$，与 SAM image encoder 输出格式对齐。

本文实现并评估了三种 adapter 变体（`dinosam/model/adapters/__init__.py:21-32`）：

| Adapter | 空间操作 | 残差结构 | 参数量 |
|---|---|---|---|
| **FCAdapter** | 无（纯通道 MLP） | LayerNorm 门控 + 线性投影 | ~0.15M |
| **Mona** | 多尺度深度可分离卷积（3×3, 5×5, 7×7 均值 + 1×1） | LayerNorm 门控 + 空间卷积 + MLP | ~1.5M |
| **DualAttnAdapter** | 位置注意力（PAM）+ 通道注意力（CAM），并行叠加 | 全局残差（每 adapter 一个） | ~1.8M |

三种 adapter 共享统一的接口签名 `forward(x, hw_shapes)`：
- **FCAdapter**（`adapters/fc_adapter.py`）：最简单的适配器，在通道维进行降维→GELU→升维的瓶颈变换，通过可学习标量门控 $\gamma$ 和 $\gamma_x$（初始值 $10^{-6}$ 和 1.0）控制 identity 分支与变换分支的混合比例。无空间操作，计算量最小，但缺乏空间上下文建模能力。
- **Mona adapter**（`dinosam/model/mona.py`）：在瓶颈维度上引入多尺度空间卷积——3×3、5×5、7×7 深度可分离卷积的输出取平均，经 1×1 投影后与 identity 分支相加。这种设计在保持参数量可控的前提下，捕获了多感受野的局部空间结构。
- **DualAttnAdapter**（`adapters/dual_attn_adapter.py`）：基于 DANet 的双注意力机制，并行运行位置注意力模块（PAM，计算 $(H \times W) \times (H \times W)$ 空间自注意力）和通道注意力模块（CAM，计算 $C \times C$ 通道自注意力），两者输出取平均后与 identity 分支做单次全局残差。去除了 DANet 原版各模块内部的逐模块残差，避免与全局残差的重复叠加。

实验表明 Mona 在分割和深度两项指标上均优于 FC 和 DualAttn（详见实验章节），后续 DPT 融合方案中以 Mona 作为默认 adapter。

## 4 DPT 多层特征融合

### 4.1 动机与观察

使用 DINOv3 单层（最后一层）特征存在一个显著问题：虽然高层 token 富含语义信息，但分割所需的细粒度空间细节在逐层抽象过程中被削弱。在替换 SAM encoder 的初期实验中，DINOv3 的强语义编码能力反而导致了细胞分割性能的退化（相对于 SAM encoder baseline）——模型"理解"了细胞，但定位精度下降。受 SegDINO \cite{segdino} 中 DPT（Dense Prediction Transformer）思想的启发，本文从 DINOv3 的不同中间层提取特征并融合，以同时保留低层的空间细节和高层的语义判别力。

### 4.2 融合架构

当 `adapter_type = "dpt_simple"` 时，模型启用 DPT 多级特征融合路径（`dinosam/model/dinov3_encoder.py:121-127`）：

```
backbone.get_intermediate_layers(x, n=dpt_layers)
      ↓          # list of n tensors: [(B, 4096, 768)]ₙ
DPTHead(features, patch_h=64, patch_w=64)
      ↓          # DPT 融合头（dinosam/model/dpt_heads.py:31-61）
(B, 768, 64, 64)
      ↓  flatten → (B, 4096, 768)
adapter1 → adapter2 → projection → (B, 256, 64, 64)
```

**DPTHead**（`dpt_heads.py:5-61`）的设计采用全统一分辨率的简化版本，所有中间层 patch token 处于同一空间尺度 $64 \times 64$，无需 Resize/Upsample 操作：

1. **逐层投影**：每个中间层的 token 序列 $(B, N, 768)$ 被 reshape 为 $(B, 768, 64, 64)$，经 $1 \times 1$ 卷积投影到 256 维特征空间；
2. **逐层精炼**：各层投影结果经 $3 \times 3$ 卷积精炼，捕获局部空间关系；
3. **拼接融合**：$n$ 个 $\in \mathbb{R}^{B \times 256 \times 64 \times 64}$ 的特征图在通道维拼接为 $(B, 256n, 64, 64)$；
4. **输出投影**：最后用 $1 \times 1$ 卷积将多级特征压缩回 768 维 $(B, 768, 64, 64)$，与单层 adapter 路径的输出维度一致。

DPTHead 支持任意层数（`n_layers` 参数），`DPTSimpleHead` 是其 $n=4$ 的特化封装（向后兼容）。

### 4.3 层选择消融

固定每分支 4 层的前提，本文对 DINOv3 的 12 层 ViT 进行了系统的层选择消融实验（$n\_sub=8$ 迭代评估，0\_sam 测试集）：

| dpt_layers | 分割 Dice | 深度 MAE ↓ | 说明 |
|---|---|---|---|
| 2,5,8,11（默认） | 0.9587 | 6.18 | 等间隔均匀采样 |
| 0,3,6,9 | 0.9593 | **6.10** | 偏浅层组合，深度最优 |
| **3,6,9,11** | **0.9637** | 7.06 | 偏深层组合，分割最优 |
| 0–11 全部 12 层 | 0.9554 | 7.40 | 全层融合，两项均垫底 |

消融结果揭示了一个关键现象：**分割和深度任务对 DINOv3 特征层的最优偏好不一致。** 分割任务受益于较深层的语义特征（3,6,9,11 取得最高 Dice），而深度回归任务更依赖较浅层的纹理和结构信息（0,3,6,9 的深度 MAE 最低）。此外，全部 12 层融合引入过多冗余特征，在两项任务上均表现最差，这表明多级特征融合的质量取决于层选择策略，而非层数。

## 5 任务解耦的双分支 DPT 层选择（设计）

> **注意：** 本节描述的机制基于已 Review 通过的设计规范（`docs/superpowers/specs/2026-07-16-dual-dpt-layers-design.md`，rev3 Approved），**代码实现和实验验证为进行中（TBD）**。本节写为完整方法以保持研究思路的连贯性；消融实验已确认层偏好的任务差异（§4.3），此处是建筑学解决方案。

### 5.1 双头架构

受 §4.3 层消融结果的启发，本节提出**任务解耦的双分支 DPT 配置**：mask 分支和 depth 分支各自使用最优的 DINOv3 中间层组合来构建其 image embedding，而非共享同一个 DPT 头输出。

- Mask 分支使用 `dpt_layers = [3, 6, 9, 11]`（深层语义，优化分割精度）；
- Depth 分支使用 `dpt_layers_depth = [0, 3, 6, 9]`（浅层纹理，优化深度估计）。

双头模式由新增参数 `--dpt_layers_depth` 触发。不提供此参数时，模型退化为 §4 描述的单头共享模式，保持完全向后兼容。

**显式校验**：`--dpt_layers_depth` 仅在 `encoder=dinov3` 且 `adapter_type=dpt_simple` 时合法，否则直接报错退出（CLI 层校验，防止静默忽略）。两组层配置经 `sorted(set(...))` 归一化，确保与 backbone `get_intermediate_layers` 的升序特征返回一致。

### 5.2 编码器扩展

双头模式下 `DINOv3MonaEncoder` 的模块结构为：

| 组件 | Mask 分支 | Depth 分支 |
|---|---|---|
| DPT 头 | `dpt_head` | `dpt_head_depth` |
| Mona adapter 1 | `adapter1` | `adapter1_depth` |
| Mona adapter 2 | `adapter2` | `adapter2_depth` |
| 线性投影 | `projection` | `projection_depth` |

mask 分支保留原参数名（`dpt_head` / `adapter1` / `adapter2` / `projection`）是向后兼容的关键：关闭双头模式时 state_dict 键与旧版逐字节一致。

**Backbone 只前向一次**（关键性能决策）：取两组层的并集 `union = sorted(set(dpt_layers) ∪ set(dpt_layers_depth))`，一次性调用 `get_intermediate_layers(x, n=union)`，然后按 union 位置索引将特征分发给 mask 和 depth 分支各自的 DPTHead。双分支的独立 head + adapter + projection 链为完全并行计算，相对 12 层 ViT backbone 的额外开销 <5%。

Forward 返回值从单张 feature map 扩展为字典：

```python
# 双头模式
return {"mask": emb_mask, "depth": emb_depth}, input_size
# 单头模式（默认，向后兼容）
return emb, input_size
```

`DepthSam.forward_mask` 和 `DepthSam.forward_depth` 在函数体首条语句做分支选择：

```python
if isinstance(image_embeddings, dict):
    image_embeddings = image_embeddings["mask"]   # 或 "depth"
```

### 5.3 训练阶段的冻结语义

双头模式下对现有冻结逻辑做了必要性修正：

| 阶段 | `*_depth` 编码模块 | 原因 |
|---|---|---|
| Phase 1（纯 mask） | **冻结** | depth 分支编码模块尚未从 mask 分支继承有效权重，不参与训练 |
| Phase 2（depth 训练） | **解冻** | depth 分支的编码模块与 `outer_prompt_encoder` + `depth_decoder` 一同训练 |

Phase 2 的 mask 分支编码模块（`dpt_head` 等）维持冻结现状。

### 5.4 Warm-Start 初始化

Phase 2 加载 phase1 checkpoint 后，双头模式下执行 warm-start：

- `adapter1_depth ← adapter1`、`adapter2_depth ← adapter2`、`projection_depth ← projection` 逐参数复制；
- `dpt_head_depth` **保持随机初始化**，因为两组层的层数和语义不同，同层数复制不适用于本场景的层差异化设计。

warm-start 仅在 trainer `run_phase2` 加载 phase1 checkpoint 时触���（双头模式下无条件执行），evaluate 不做 warm-start（评估不训练，随机 depth 分支的深度无意义）。

### 5.5 Checkpoint 兼容

双头 checkpoint 与旧单头 checkpoint 的互操作有明确定义（6 种场景的兼容矩阵见设计文档 §Checkpoint 兼容与 warm-start），核心只保留与本 Method 叙述相关的两点：

- 双头 mode + phase2 加载 phase1 checkpoint：`strict=False` 加载后无条件 warm-start（mask 分支权重匹配，depth 分支覆盖为 mask 分支副本），不报错；
- evaluate 遇到单/双头不匹配：跳过不匹配的 checkpoint 并打印提示，继续评下一个，不硬退出——支持"单头 phase1 + 双头 phase2"混合评估工作流。

## 6 Mask 引导的深度回归

### 6.1 TwoWayTransformer 作为深度解码核心

SAM 的 TwoWayTransformer 原生设计用于 mask decoder 中实现"prompt tokens ↔ image features"的双向交叉注意力：prompt tokens（IoU token + mask tokens）通过自注意力更新后，经交叉注意力从图像特征中查询空间信息，同时图像特征也通过反向交叉注意力接收 prompt 的语义约束。这一机制天然适合 mask 引导的深度回归：将 mask 信息编码为 prompt tokens，与图像特征通过双向注意力交互，使得深度预测以被选中的区域为条件。

深度解码器 `DepthMaskDecoder`（`dinosam/model/depth_decoder.py:10-92`）的核心特征信息流是通过掩码投影从图像嵌入和位置编码生成密集嵌入，通过点提示生成稀疏嵌入，然后 depth token 和 mask token 拼接后与 sparse prompt embeddings 一起进入 TwoWayTransformer 进行双向交叉注意力，最后深度 token 的输出（transformer 每个位置的输出）经 depth_prediction_head（3 层 MLP，隐藏维 256）回归标量深度。

**权重初始化。** 深度分支的 `outer_prompt_encoder` 从 SAM 的 inner prompt_encoder 完整复制所有权重（`DepthSam.init_depth_from_sam`，`depth_sam.py:84-142`）。`DepthMaskDecoder` 中与 SAM mask_decoder 结构对应的组件（transformer、output_upscaling、output_hypernetworks_mlps 首组、mask_tokens 首组）从 SAM 迁移权重；`depth_token` 继承 `iou_token` 的初始嵌入；`depth_prediction_head` 保持随机初始化——它在 SAM 中没有对应物。对于 `depth_transformer_type = "dual_attn"` 的变体（§6.2），transformer 权重跳过迁移而使用随机初始化，因其结构与 `TwoWayTransformer` 不兼容。

### 6.2 深度 Transformer 变体

本文评估了 3 种深度解码器的 transformer 实现（`depth_sam.py:69-81`）：

| Transformer | 来源 | 说明 |
|---|---|---|
| **TwoWayTransformer** | SAM mask_decoder | 双向交叉注意力，从 SAM 权重初始化 |
| **DualAttnTransformer** | 自研 | 自定义双重注意力，结构与 TwoWayTransformer 不同，随机初始化 |
| **Simple** | — | 无 transformer 也无 decoder，仅全局平均池化 + MLP 直出深度（旁路设计） |

Simple 模式不包含 `outer_prompt_encoder` 和 `DepthMaskDecoder`，深度分支仅由 `AdaptiveAvgPool2d → Linear(256→1024) → ReLU → Linear(1024→256) → ReLU → Linear(256→1)` 组成，完全跳过 mask prompt 路径。此模式作为消融基线：验证 mask 引导的 TwoWayTransformer 是否显著优于无 mask 条件的纯图像特征回归。

### 6.3 深度标签归一化

数据集按深度类别文件夹组织（层次目录名为 `f100`, `f90`, …, `0`, …, `+100`），文件夹名编码了该样本相对焦平面的有符号离焦距离。`DepthDataset`（`dinosam/dataset/depth_dataset.py:9-12`）将文件夹名解析为深度标签：`f` 前缀表示负值（焦平面上方），否则为正值（焦平面下方）。训练时深度标签除以 100 归一化到 $[-1, 1]$（`depth_dataset.py:102`），评估时乘以 100 恢复原始标度。

## 7 训练策略

### 7.1 设计动机：功能耦合驱动的两阶段解耦

本模型的架构存在一个内在的功能耦合：**深度分支的输入直接依赖于分割分支的输出**。具体而言，`forward_depth` 将分割分支产出的低分辨率掩码 `low_res_masks` 作为 dense prompt 注入 outer prompt encoder（`depth_sam.py:320-322`），TwoWayTransformer 以该 mask prompt 为条件执行双向交叉注意力并回归深度值。因此，深度回归的质量从根本上受制于 mask prompt 的质量——若分割分支尚未收敛、输出的掩码粗糙或不完整，深度分支收到的 prompt 包含错误的区域信息，深度梯度将建立在无意义的输入条件之上，导致训练信号恶化甚至模型无法收敛。

这一耦合关系排除了端到端联合训练的可能性：(1) 联合训练早期，分割分支尚未形成可靠 mask，深度分支收到的近乎随机噪声作为 prompt，深度 loss 的梯度反向传播会通过共享的图像 encoder 特征图扰动 mask 分支的训练，形成"低质量 mask → 错误深度梯度 → 分割训练受干扰 → mask 持续低质量"的恶性循环；(2) mask 训练使用的 dice loss 与深度回归使用的 MSE loss 在梯度量级和优化方向上差异显著，联合优化需要在两种竞争性梯度信号之间折中，任何一方的学习率缩放都无法同时满足两者的收敛需求。

因此，本文采用**两阶段解耦训练策略**：首先独立训练模型的分割能力直至 mask 质量稳定，随后冻结全部 mask 分支参数，仅在高质量固定 mask prompt 的条件下训练深度回归分支。两阶段训练完成后，分割和深度参数各自由对应的 loss 独立优化至收敛，功能耦合仅存在于前向推理路径中，训练动态完全解耦。

### 7.2 初始点提示

训练和评估使用确定性的点提示：取 GT mask 中面积最大的连通域质心作为唯一初始正点击（`depth_dataset.py:55-86`）。该设计避免了随机采样带来的训练噪声，使模型从最可靠的种子点出发学习迭代精化。评估时 `max_points = 8`（使用面积前 8 大的连通域），以更充分地评估迭代修正能力。

### 7.3 两阶段训练流程

训练分为两个连续阶段（`dinosam/train/trainer.py:414-561`），共享相同的 50 epoch 总量和优化器配置（AdamW, lr=$10^{-5}$, StepLR 每 10 epoch ×0.5）：

**Phase 1 — 掩码训练**（`trainer.py:414-470`）。此阶段的目标是在稳定的图像特征基础上建立高质量的分割能力，为 Phase 2 提供可靠的 mask prompt 基础。

- **冻结**：DINOv3 backbone（`freeze_image_encoder`）、深度分支全部参数（`freeze_depth_branch`：包括 `outer_prompt_encoder` 和 `depth_decoder`；双头模式 §5 下额外冻结 `dpt_head_depth` / `adapter1_depth` / `adapter2_depth` / `projection_depth` 四个编码模块，`depth_sam.py:150-160`）
- **可训练**：adapter1、adapter2、projection（图像特征适配链 + 维度对齐）、SAM prompt_encoder、SAM mask_decoder（分割核心）
- **损失**：$\mathcal{L}_{\text{P1}} = \mathcal{L}_{\text{dice}} + \mathcal{L}_{\text{iou}}$，两项等权重相加，细节见 §7.4。可选加 boundary loss（§7.4 消融项），但默认不启用
- **输出**：`phase1_best.pt` —— 保存完整的模型 state_dict（包含 mask 分支已训练权重 + depth 分支随机初始值），以及 optimizer/scheduler 状态

**Phase 2 — 深度训练**（`trainer.py:473-561`）。此阶段的目标是在冻结的高质量 mask prompt 条件下，独立训练深度分支使其学会从"区域条件 + 图像特征"中回归深度。

- **加载与重置**：从 Phase 1 的 `phase1_best.pt` 用 `strict=False` 加载全部权重（mask 分支参数精确匹配，depth 分支随机值被覆盖）。随后立即调用 `model.init_depth_from_sam()`（`depth_sam.py:84-142`）将 depth 分支的 `outer_prompt_encoder` 和 `DepthMaskDecoder` 用 SAM 权重**重新初始化**——因为 Phase 1 中 depth 分支完全冻结、从未接收过有效梯度更新，其保存的随机初始值没有保留价值，用 SAM 预训练权重做 warm-start 能显著加速 Phase 2 收敛
- **冻结**：先冻结全部参数（`trainer.py:483-484`），再选择性解冻。最终 mask 分支的全部组件维持冻结：DINOv3 backbone、adapter1、adapter2、projection、SAM prompt_encoder、SAM mask_decoder
- **可训练**：仅 `outer_prompt_encoder` 和 `depth_decoder`（`trainer.py:490-493`）；双头模式 §5 下额外解冻 `*_depth` 四个编码模块；Simple 模式下仅解冻 `simple_depth_head`（纯 MLP，无 decoder）
- **损失**：$\mathcal{L}_{\text{P2}} = \mathcal{L}_{\text{depth}}$（仅深度 MSE，`trainer.py:243-244`）。mask 分支的 dice loss 仅在 log 间隔的 batch 上计算用于监控（`trainer.py:252-258`），不参与梯度更新（`loss = depth_loss_weight * depth_loss`，mask 分支处于 `no_grad` 或冻结状态）
- **输出**：`phase2_best.pt`

**Phase 2 损失不包含 mask 损失的根本原因。** Phase 2 的 deep 损失算式中不加入分割损失并非随意简化，而是由冻结语义直接决定的：(1) mask 分支全部参数 `requires_grad = False`，分割 loss 即使计算也无法产生有效梯度更新；(2) depth decoder 输出的辅助 mask（`decoder_masks`）仅用于迭代式点采样（§7.5），其 dice loss 仅做日志监控，不应与深度回归共享优化目标——否则会导致深度分支偏向于"输出易于被监督的辅助 mask"而牺牲深度预测精度。

### 7.4 损失函数

**Dice Loss**（`dinosam/loss/dice.py:5-16`），用于分割质量监督，定义在 full-res 预测 mask 与 GT mask 之间：

$$
\mathcal{L}_{\text{dice}} = 1 - \frac{1}{B}\sum_{b=1}^{B} \frac{2\sum_{i,j} P_{b,i,j} \cdot T_{b,i,j} + \varepsilon}{\sum_{i,j} P_{b,i,j} + \sum_{i,j} T_{b,i,j} + \varepsilon}
$$

其中 $P_{b,i,j} = \sigma(\hat{M}_{b,i,j})$ 为 sigmoid 概率，$T_{b,i,j} \in \{0, 1\}$ 为二值 GT mask，$\varepsilon = 10^{-6}$。

**IoU 预测损失**：SAM 的 mask decoder 为每张 mask 同步输出一个预测的 IoU 置信度评分，用 MSE 对该预测评分做监督——将预测 IoU 与真实 IoU（sigmoid 阈值化后的 mask 与 GT 的交并比）对齐：

$$
\mathcal{L}_{\text{iou}} = \frac{1}{B}\sum_{b=1}^{B} (\hat{r}_b - \text{IoU}(\hat{M}_b, M_b))^2
$$

**深度 MSE Loss**（`dinosam/loss/depth_loss.py:5-7`），归一化深度空间中的均方误差：

$$
\mathcal{L}_{\text{depth}} = \frac{1}{B}\sum_{b=1}^{B} (\hat{z}_b - z_b)^2
$$

其中 $\hat{z}_b, z_b \in [-1, 1]$ 为归一化的预测/真实深度值（原始深度范围 $[-100, 100]$ μm 除以 100，`depth_dataset.py:102`）。

**Boundary Loss（消融项）**（`dinosam/loss/dice.py:19-78`）。可选启用的边界感知损失（`--boundary_loss`），由边界 Dice 和距离加权 BCE 两项组成：对 GT mask 做 $\text{width}=3$ 的形态学腐蚀提取内边界带，仅在该边界带上计算 Dice loss；用 kornia 的 GPU 距离变换计算每个像素到边界的归一化距离，距离越近 BCE 权重越高（最高 5×）。实验显示该损失产生了系统性过分割（mona_iter8 的 Recall≈0.99 / Precision≈0.87），分割 Dice 从 0.9500 降至 0.9243。本文**默认不启用 boundary loss**。

### 7.5 迭代式 Prompt 精化：充分训练 Prompt-Image 交互

SAM 的核心能力在于其 prompt encoder 和 mask decoder 之间的交互机制：给定一组稀疏 prompt（点/框）和可选的稠密 prompt（mask），模型通过 TwoWayTransformer 的双向交叉注意力从图像特征中查询被 prompt 指定的空间区域，并输出对应的分割掩码。这一交互的质量决定了模型在推理时能否有效利用不同数量和质量的 prompt 产生准确的预测。

然而，若训练时始终使用固定的初始 prompt（如仅一个正点击点），模型学到的仅是"单点→完整 mask"的映射，无法充分利用 SAM 逐步精化的潜力——即模型从未见过"不完美预测→根据误差补充 prompt→修正预测"的训练信号。为此，本文在训练中引入**迭代式 Prompt 精化**（`n_sub_iterations = 8`，`dinosam/train/iterative.py`），使模型在每一轮 sub-iteration 中经历完整的"预测→误差检测→prompt 扩充→重新预测"循环，从而学会利用更新后的 prompt 逐步逼近 GT mask。

具体而言，当前轮 mask 预测与 GT mask 对比后，从两类误差区域各随机采样一个点作为下一轮的额外正/负 prompt（`dinosam/prompt/iterative.py:16-91`）：

- **正点**（label=1）：从"GT 有、预测无"的遗漏区域随机采样（`iterative.py:46-65`），优先从遗漏前景中采样，若无则回退到正确重叠区域或 GT 前景中心
- **负点**（label=0）：从"预测有、GT 无"的误报区域随机采样（`iterative.py:68-83`），优先从误报背景中采样，若无则回退到 GT 边界外围或任意背景点

新点坐标从低分辨率 mask 空间（256×256）缩放到原始图像空间后附加到当前 prompt 集合。同时以 $p=0.5$ 的概率将上一轮的低分辨率 mask logits 作为 `mask_input` 传给下一轮（`iterative.py:79-82`）——这使模型学习到"当可获前一预测的 mask 信息时，如何利用它辅助后续精化"。评估时 `mask_prob = 0.0`，保持确定性推理。

**Phase 1 与 Phase 2 的迭代模式有本质区别**，这一区别源于两阶段的冻结语义差异：

**Phase 1 迭代**（`iterative_mask_step`，`iterative.py:111-198`）：迭代完全发生在 mask 分支内部——每轮用更新后的 prompt point + 可选的 mask input 重新运行 SAM 的 `forward_mask`，新的 mask 预测用于采样下一轮的 prompt。所有 sub-iteration 的 dice loss 和 IoU loss 累积后取均值，使模型学会在一次推理中通过多轮迭代逐步缩小 mask 误差。

**Phase 2 迭代**（`iterative_depth_step`，`iterative.py:201-302`）：迭代路径不同于 Phase 1——mask 分支**仅运行一次**（`iterative.py:227-233`），其权重已冻结，输出的 `low_res_masks` 作为固定 mask prompt 在深度分支的全部 sub-iteration 中被复用（`iterative.py:248`）。深度分支自身迭代 $n\_sub$ 次：每轮 `forward_depth` 输出两个结果——深度预测值 `depth_pred` 和辅助 decoder mask `decoder_masks`。深度预测的 MSE loss 在各轮间累积并取均值，构成唯一的优化目标（`iterative.py:296`）；decoder mask 与 GT mask 的 dice loss 仅用于日志监控，**不参与梯度更新**（`loss = depth_loss_weight * avg_depth_loss`，line 296，mask 分支被冻结）。

辅助 decoder mask 在 Phase 2 中承担一个关键功能：为下一轮 sub-iteration 提供**误差提示的点采样依据**。每轮结束后，decoder mask 被下采样到 256×256、阈值化后与 GT mask 对比，从误差区域采样新的正/负点（`iterative.py:267-274`），缩放到原始图像空间后附加到深度分支的 prompt 坐标集上（`iterative.py:286-291`）。这意味着深度分支在以一种**自监督式闭环**学习：它自身的 mask 预测质量决定了下一轮 prompt 的精度，prompt 精度又影响深度回归的条件信息质量——模型被迫在学习深度输出的同时，也学会为 TwoWayTransformer 提供准确的辅助 mask 以改进条件推理。

两阶段迭代模式的设计体现了"分割稳定后深度自精化"的哲学：Phase 1 建立分割能力的"基础设施"（冻结的 mask prompt 来源），Phase 2 在此基础上训练深度分支学会利用自身的 mask 预测进行 prompt 自纠正。推理时两个分支串联——mask 分支迭代至收敛，最终的低分辨率 mask 与累积 prompt 一并注入 frozen 的深度分支、直接推理深度，无需额外的深度分支迭代。

## 8 推理

推理时（`dinosam/evaluate.py:31-184`），用户提供一个点击点，模型执行迭代式 mask 精化（n_sub_iterations=8）：初始 mask 从确定性质心点出发，后续各轮自动采样正/负点进行修正。精化后的低分辨率 mask（detach）与累积的 point prompts 一起送入深度分支的 `outer_prompt_encoder`，作为密集提示和稀疏提示共同参与 TwoWayTransformer 推理。单次前向同时输出最终的 full-res mask 和深度预测值。
